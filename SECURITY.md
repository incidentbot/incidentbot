# Security Policy

## Supported Versions

| Version  | Supported          |
| -------- | ------------------ |
| v2.x     | :white_check_mark: |
| < v2.0.0 | :x:                |

## Reporting a Vulnerability

Please open an issue against this repository and add the `security` label. If the vulnerability is sensitive, use [GitHub's private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) instead of a public issue.
